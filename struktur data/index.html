Apa itu Struktur Data?

Cara kita menyimpan dan menyusun data di memori komputer agar bisa digunakan secara efisien. Ibarat menata buku di rak, jika rapi, mencarinya akan sangat cepat!

Mengapa Stack Penting?

Dalam komputer, ada banyak proses yang mengharuskan kita mengurus data dari yang "paling baru" ke yang "paling lama". Di situlah Stack digunakan.

Contoh Sehari-hari

  • 🥞 Tumpukan piring di prasmanan
  • 🔄 Tombol "Undo" di Word (Ctrl+Z)
  • ⬅️ Tombol "Back" di Web Browser

Pengertian Stack

"Stack adalah struktur data linear yang bekerja dengan prinsip LIFO (Last In, First Out)."

Data yang TERAKHIR dimasukkan ke dalam tumpukan, otomatis menjadi data yang PERTAMA kali dikeluarkan.

Implementasi Menggunakan Array

Di C++, Stack paling sederhana dibuat memakai Array. Bayangkan indeks array ini berdiri menyusun laci rak dari bawah ke atas.

📦

Kapasitas (MAX)

Batas maksimal elemen. Karena array statis, ukuran stack ditentukan sejak awal.

🎯

Variabel Penunjuk top

Sebuah angka (integer) yang menunjuk ke indeks elemen teratas saat ini.

⚠️ Dua Kondisi Penting Array:

top == -1

Stack KOSONG (karena array dimulai dari indeks 0).

top == MAX - 1

Stack PENUH (mencapai batas akhir indeks array).

5 Operasi Dasar Stack

📥 push(data)

Menyisipkan data baru di posisi paling atas (TOP) dari stack.

📤 pop()

Mengambil & menghapus data teratas dari stack.

👀 peek() / top()

Mengintip nilai teratas tanpa menghapusnya dari tumpukan.

🪹 isEmpty()

Mengecek apakah stack sedang kosong (True/False).

🧱 isFull()

Mengecek apakah kapasitas array sudah penuh (True/False).

Detail Operasi: PUSH()

Alur Logika:

  1. Cek apakah stack penuh (Overflow).
  2. Jika tidak, naikkan batas TOP: top++
  3. Simpan data di array indeks TOP: arr[top] = data
void push(int data) {
    if (isFull()) {
        cout << "Stack Penuh!";
    } else {
        top++;
        arr[top] = data;
    }
}
Simulasi: push(40), lalu push(15)
[0]40
[1]15 ← top=1
[2]

Detail Operasi: POP()

Logika: Cek Underflow ➔ Ambil nilai arr[top] ➔ Turunkan top--.

⚠️ Ingat! Fungsi pop tidak menghapus fisik memori array, hanya menggeser batas penunjuk (top) ke bawah.

Awas Error! Overflow & Underflow

🌊

⚠️ Stack Overflow

Memaksa memanggil push() saat array sudah penuh. Program akan crash karena mencoba mengakses indeks memori yang tidak ada.

"Terus menumpuk piring sampai melewati plafon. Piringnya akan jatuh dan pecah!"
Error: Index Out of Bounds
🕳️

🕳️ Stack Underflow

Memaksa memanggil pop() atau peek() saat array kosong (top == -1). Tidak ada data yang bisa diambil.

"Mencoba mengambil piring dari rak yang kosong melompong. Anda hanya menggenggam angin."
Pencegahan: Gunakan isEmpty()

Kode Lengkap (C++)

stack_array.cpp 
#include <iostream>
using namespace std;

#define MAX 5 // Kapasitas stack

class Stack {
private:
    int arr[MAX];
    int top;

public:
    Stack() { top = -1; } // Constructor, top set ke -1

    bool isFull() { return top == MAX - 1; }
    bool isEmpty() { return top == -1; }

    void push(int data) {
        if (isFull()) cout << "Stack Overflow\n";
        else {
            top++;
            arr[top] = data;
        }
    }

    void pop() {
        if (isEmpty()) cout << "Stack Underflow\n";
        else {
            cout << "Hapus: " << arr[top] << endl;
            top--;
        }
    }
    // ... function peek() ada disini
};

int main() {
    Stack s;
    s.push(40); s.push(15);
    s.pop();
    return 0;
}

Penjelasan Kode Program

1. Deklarasi (Constructor)

Objek Stack dibuat, indeks memori disiapkan, dan nilai awal top = -1.

2. Eksekusi Push

Pastikan isFull() == false. Lalu naikkan pointer top++, dan timpa indeks array tersebut dengan angka baru.

3. Eksekusi Pop

Pastikan isEmpty() == false. Ambil nilai di ujung array, lalu cukup turunkan pointernya top--.

↩️

Sistem Undo/Redo

Setiap kali mengetik, aksi di-push. Saat Ctrl+Z, teks terakhir di-pop (dibatalkan).

🌐

Browser History

⚙️

Call Stack (Pemrograman)

Sistem operasi menyusun eksekusi fungsi. Fungsi yang terakhir dipanggil adalah yang pertama selesai (return).

🧮

Evaluasi Ekspresi Matematika

Membantu compiler (mesin komputer) memecahkan tanda kurung dan rumus yang rumit.

Notasi Ekspresi Aritmatika

Manusia dan Komputer membaca rumus secara berbeda. Perhatikan letak posisi Operatornya (+, -, *, /).

INFIX

Operator di Tengah.
(Standar baca manusia)

A + B

PREFIX

Operator di Depan.
(Polish Notation)

+ A B

POSTFIX

Operator di Belakang.
(Format baca mesin)

A B +

Konversi: Infix menjadi Postfix

Soal Infix
(A + B) * C
Langkah 1 (Kurung Prioritas) AB+ * C
Langkah 2 (Pindah Operator) AB+C*
⚙️

Secara behind the scene, Komputer menggunakan memori Stack untuk menyimpan sementara operator logika (+, -, *) ini sesuai derajat prioritasnya, agar bisa diubah menjadi format Postfix yang langsung dapat dieksekusi secara instan.

Kelebihan & Kekurangan

👍 Kelebihan

  • ✔ Sangat sederhana dan mudah dikoding (diimplementasikan).
  • ✔ Sangat cepat dan efisien, karena kompleksitas pencariannya O(1).
  • ✔ Hemat memori karena array ukurannya tetap, tidak butuh pointer tambahan.

👎 Kekurangan

  • ✖ Kapasitas Kaku: Jika memori penuh, program bisa eror. Jika berlebih, memori terbuang sia-sia.
  • ✖ Akses Terbatas: Kita tidak bisa menyisipkan, menghapus, atau membaca data di tengah tumpukan. Hanya di pucuk!

Kesimpulan Akhir

  • 3

    Meskipun sederhana, strukturnya memegang peranan krusial sebagai fondasi di dalam sistem operasi dan aplikasi modern.
